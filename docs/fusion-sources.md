# Fusion sources and temporal evidence

FusionSourceReference pins logical source/family, artifact and version, provider, model/spec, target/horizon, output kind, unit, calibration state, artifact availability, and an exact anchor output. Observations pin each exact output, sample/security/origin and availability. Canonical ordering does not select contributors. Duplicate logical producers require explicit distinct versions; duplicate identical producers remain invalid.

Closed native adapters accept AFRE-5 point, AFRE-6 probabilistic, AFRE-7 calibrated, AFRE-10 event, AFRE-11 regime, AFRE-12 mixture, AFRE-13 nonlinear, AFRE-14 sequence and explicitly supplied AFRE-16 residual signals. An explicit POINT adapter takes a native probability forecast's scalar prediction without claiming a probability law. Probability fusion uses exact compatible laws and retains calibrated versus uncalibrated state. No automatic residualization or source selection occurs.

ExternalFusionDefinition is provider-neutral data: an exact provenance reference, provider/version, declared target/kind/unit and a closed base-prediction protocol. The fixed historical protocol explicitly has no fitted base model; the out-of-sample protocol pins base fit cutoff and TRAIN sample IDs. A source trained on its own meta-TRAIN sample is rejected. No external engine imports, executable definitions, provider-selected paths or networking exist.

AvailabilityEvidence distinguishes upstream publication, upstream source availability, AFRE receipt, ingestion, computation and final availability. A provider timestamp is not AFRE availability. Live final availability cannot precede AFRE receipt. A 10:00 publication received at 10:02 is unusable at 10:01. An archive downloaded months later cannot be silently backdated. Qualified historical-delivery evidence from an approved attestor may establish historically knowable availability while preserving later actual observation/ingestion/computation clocks. Historically knowable, actually observed and later reconstructed remain separate claims.

Source outputs must match exact target, horizon, kind, unit, sample and origin and be usable by that origin cutoff. Artifact availability and each observation's availability are checked separately. A correction creates a new observation/output identity; prior fused bytes remain fixed. AFRE-15 uncertainty and AFRE-17 stability are separate post-hoc metadata, never automatic alpha or weight inputs.
