# Exact health, cost and research context

AFRE-22 health context is explicit per participant. Snapshots must match the native producer, target/horizon, current evaluation window and truth cutoff, and be available by actual evaluation. Allowed/required statuses belong to frozen criteria. Health context != automatic promotion. Correcting a health snapshot creates a new evidence/run identity.

A `ChallengeCostPlan` pins a representative native AFRE-18 `CostScenario`. AFRE-18 scenarios bind source forecasts, so participant-specific scenario fingerprints differ. Equivalence excludes only descriptive scenario name, source IDs and participant uncertainty annotations. All economic assumptions must be identical: sample grid, target/fold, exposure mapping, native cost components/model/version and input vintages, liquidity, participation, currency, timing, missingness, declaration and turnover/contribution conventions. The shared AFRE-23 plan is the comparison scenario identity.

Each participant supplies a native `CostAwareEvaluation` with the same cutoff/seal. Every common sample must have the exact shadow source and explicit truth in its native cost row. Gross contribution, cost, net contribution and turnover are evaluated separately from those rows on the common support; unrelated native aggregate metrics are never compared. No exposure/cost model is refit. Optional break-even diagnostics require exact native evaluation/common support and identical component/unit semantics; otherwise unavailable/incomparable. This remains hypothetical research evaluation, separate from downstream portfolio construction.

Native AFRE-19 trials, families, adjusted evidence, TEST reuse and AFRE-21 trial pools are preserved by bounded canonical certificates and audit lineage. No significance, independence or clean research history is manufactured. AFRE-20 selected-model provenance remains frozen: selection != shadow comparison. AFRE-21 weights and laws remain unchanged. Corrections cannot erase prior attempts or redefine the program. Native TEST seals and existing frozen fusion choices remain required. No TEST-driven threshold tuning is allowed.
