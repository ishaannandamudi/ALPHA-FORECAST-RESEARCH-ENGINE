# Stability evaluation and storage

`StabilityAnalysisSpec` pins target/horizon, fold, exact source forecasts and sample population, environment set, declared feature and uncertainty evidence, metrics, intersection, minimum count, baseline, weighting, sample mode, score intervals/threshold/reliability bins, quantile levels, tolerance, seed and implementation. Definitions/settings must be declared by the fold training cutoff. TEST requires an explicit native sealed assessment identity and cannot choose environments, metrics, baseline, minimums, calibration or model fits.

Point metrics reuse AFRE-5. AFRE-6 Gaussian/empirical and AFRE-12 mixture scores retain native density/atom semantics. Mixture quantiles are unavailable; they are never averaged. Calibrated intervals/quantiles/probabilities retain exact AFRE-7 marginal semantics, and a marginal-only forecast cannot fabricate a full law. Fixed reliability bins provide weighted ECE/MCE and explicit mean-probability/outcome-frequency records with empty bins preserved. Uncertainty metrics retain AFRE-15 method/units/identifiability; only exact positive-total additive closure can produce component shares. Missing uncertainty evidence for an exact intersection is unavailable.

Every metric records declared eligible population, membership-selected count, included count, excluded count, missing truth/forecast count, truth-available count, weights and effective support. A declared intersection restriction is distinguished from missing data. Insufficient, unavailable and incomparable outputs are retained with reason codes. Causal model forecasts and later TRAIN in-sample diagnostics keep their native scopes. Truth is resolved only for later assessment against exact sample-bound `TargetVintage` IDs and cutoff.

Parameter diagnostics compare supplied frozen fits. Linear affine preprocessing permits betaRaw=beta/scale and interceptRaw=intercept−ΣbetaRaw×center. Non-affine transforms are incomparable. Trees expose measured split/path recurrence, thresholds and leaf support; sequence models expose fixed readouts/decay/state parameters and readout sensitivity only. Masked sequence center effects do not claim a universal raw intercept. Projection and redundancy records retain AFRE-16 coefficient, ratio, raw-reference and incremental metrics. Parameter range/mean/median/sign fractions include zero explicitly. Supplied assignment labels do not assert an environment-specific refit or that the model was trained in that cohort.

SQLite17→18 is transactional and additive, preserving prior DDL/metadata/rows. New immutable `inv_artifacts`, `inv_records`, `inv_links` use strict hash/family/schema/relational-index/link checks and semantic replay. Low-level `get` verifies structural integrity; validated `resolve`/`get_any` also replay semantic evidence inside a pinned snapshot and scoped cache. Exact republish is idempotent. Layout and metadata corruption fail closed; older repositories reject the future store. Construction, evaluation and audit use pinned read snapshots; concurrent corrections cannot replace exact references. Writes publish completed artifacts atomically after snapshot computation.

Default hard limits:32 environments,8 explicit compounds,2,000 samples/forecasts,24 metric selectors,16 declared features,32 windows,64,000 work/grid cells,20,000 artifacts per family,8MiB payload/lineage,100,000 audit nodes and64 depth. Lower caller limits apply on reads and writes. Unified lineage traces environments, memberships, native forecasts/models, PIT event/regime/group/universe evidence, TRAIN fit records, exact evaluation truth and TEST seals. Audits explicitly state the absence of causal proof, significance, profitability, model search and automatic mutation.
