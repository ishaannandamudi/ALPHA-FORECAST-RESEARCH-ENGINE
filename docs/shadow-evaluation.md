# Shadow forecast evaluation

`ChallengeEngine.shadow` requires an existing frozen participant, program and exact native forecast/output. It never calls fitting, calibration, fusion learning, source discovery or model selection. The feature-only guard covers both construction and semantic replay, before inherited native or challenger cache access. A warm TargetVintage cache cannot bypass it.

`ShadowForecast` pins program, participant, source forecast, security/sample/origin, target/horizon, value, embedded native law identity, unit, partition, source availability, actual computation, final availability, quality and mode. `RECORDED_CAUSAL` requires native source availability at the origin cutoff and actual shadow receipt/computation no later than origin. A provider publication timestamp is not AFRE receipt.

`RECONSTRUCTED_NATIVE` explicitly permits later wrapping of an already causal native forecast. The wrapper retains its actual later computation/availability; it cannot manufacture historical native availability. Native AFRE-1 receipt, ingestion, computation and qualified historical-delivery contracts continue to apply. A later AFRE-20 designation is retrospective context, never evidence that model selection occurred at the historical origin.

Truth is loaded later through explicit `(ResearchSample, TargetVintage)` assignments. Native target origin/definition and known-by-cutoff quality are checked. Future or incomplete truth is excluded visibly. No automatic latest-vintage query is used. New source, truth or context evidence creates a new immutable run; old runs retain their exact IDs.

Native point metrics, complete-law CRPS/NLL, strict-greater-than Brier, supported quantile pinball and exact interval coverage/sharpness remain separate. A single-component fusion law supports its exact native quantiles. General mixture quantiles and unsupported output/metric combinations are unavailable, without substituting a different sample set. Coverage, sharpness, turnover and break-even comparisons are descriptive; an explicit criterion can use their raw delta with its declared direction. No universal scalar promotion score is built.
