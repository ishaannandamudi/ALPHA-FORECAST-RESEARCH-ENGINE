# Provider-neutral sequence sources

Ordinary AFRE FeatureVintage, AFRE-10 event attributes, AFRE-11 FILTERED regime probabilities, neutral external microstructure/context/options signals, AFRE-12 expert/mixture outputs and causal AFRE-13 interaction outputs are projected through existing immutable ScalarInput/InteractionValue contracts. Exact semantic definitions, units and revision/source fingerprints are preserved. AFRE-14 does not re-extract events or estimate provider regimes. SMOOTHED and EX_POST regime histories remain inadmissible.

Observation time derives from the source: ordinary effective time, external as-of time, event occurrence, regime as-of time or expert/interaction origin. Event sequences require exact occurrence evidence. Publication time, upstream source-availability time, AFRE observed/received time, ingestion time, computation time and final availability remain distinguishable through referenced AvailabilityEvidence. A provider timestamp is not AFRE availability. Live inputs cannot enter before actual receipt. Archives downloaded later remain unavailable historically unless qualified historical-delivery evidence and explicit attestor approval establish earlier delivery.

Qualified reconstruction preserves actual later AFRE receipt/ingestion/computation and separate historical knowability/delivery evidence. It does not pretend this process literally ingested the record at the historical instant. SequenceObservation also pins `afre_ready_ns` from actual source processing evidence; a later reconstructed snapshot cannot precede that time, even when source historical availability is earlier. The actual clock is propagated through neutral external expert bindings, mixture components/gating references and nonlinear inputs. Model policy rechecks approved attestors; earlier scalar admission alone does not authorize a new sequence model to trust that proof.

There are no imports of AME, MCE, EIE or options-engine code, sibling databases/paths, runtime network calls, provider-selected paths, plugins or executable sequence payloads. Canonical contracts cannot authenticate a dishonest provider timestamp or detect secretly future-derived upstream scalars; the trust boundary still requires source audits.
