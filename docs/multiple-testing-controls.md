# Multiple Testing & Research Overfitting Controls

AFRE-19 adds an immutable evidence and opportunity-accounting layer over native
AFRE-5 through AFRE-18 artifacts. Engine 0.20.0, schema 1.0, store 1.19/SQLite20,
Python 3.11+ and zero runtime dependencies. Every prior public contract remains intact.

Declare assumptions and a hypothesis, register explicit planned opportunities, freeze
an exact family with its alpha/q, dependence assumption and all correction reports,
then complete attempts under native held-out/TEST seals. Missing and failed slots count
in m. Final rejection requires a COMPLETE, caller-attested predeclared family and
supported raw evidence. OPEN/PARTIAL, adaptive/unknown or retrospective evidence is
INTERIM; INVALID is incompatible. Unsupported inference returns typed status and null
statistics, never fabricated significance.

The supported raw null is P(positive sign | nonzero sign)=1/2 about the declared null
value. It is not a generic median null when ties have asymmetric mass. Each trial uses
one frozen producer per side and exact immutable ResearchSample/TargetVintage identities.
An exact paired test subtracts the same declared metric on the exact sample/truth
intersection; exclusions remain explicit. Zeros are excluded, recorded separately and
minimum support applies to nonzero signs. Independence/fair-sign/pairing assumptions are
caller attestations; native label intervals are also checked for overlap per security.

One-sided tails and symmetric two-sided tails use integer binomial sums divided by 2^n,
with no asymptotic approximation. IEEE754 output rounding remains finite precision;
extreme positive tails below the smallest subnormal saturate conservatively at that
smallest positive float. See [the exact binomial definition](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.binomtest.html).
SciPy is a reference only and is not imported.

P-value != effect size. Descriptive sample median minus null and native metric units are
stored independently. Corrections never mutate the effect; CI/SE, normal/correlation
inference and deflated performance are explicitly unsupported. Statistical significance
is neither causal identification nor trading profitability. Multiplicity adjustment
cannot remove leakage, data snooping, adaptive generation, publication bias or drift.

Runtime data is closed typed canonical JSON, never executable hypothesis logic. SQLite
publication requires a transaction, checks fingerprints/projections/links and replays
semantic evidence. Read snapshots freeze source/truth membership before atomic publication.
Provider-neutral clocks and native causal admission stay inherited; provider publication
is never substituted for physical AFRE receipt without qualified reconstruction evidence.
No runtime network, external-engine imports, shell, pickle, dynamic imports or dependencies.
