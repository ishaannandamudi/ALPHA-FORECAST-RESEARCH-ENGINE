# Error drift and performance decay

Later-cutoff diagnostics join exact native ResearchSample and TargetVintage identities. Unknown truth at the declared cutoff is excluded with its sample and reason. Native truth availability is verified before calculation; health availability cannot be backdated to the forecast origin.

Bias is prediction minus truth. MAE, MSE, RMSE, population error variance and Type-7 signed-error quantiles retain native support. R² uses exact compatible target units and is unavailable with a degenerate truth denominator. IC/rank IC average valid same-origin cross-sectional Pearson/Spearman correlations; undefined or undersupported cross sections do not become zero. Current-minus-reference is the recorded delta. Positive loss delta means worse; positive R²/IC/rank IC delta means better. Rules explicitly choose CURRENT, DELTA or RATIO, with undefined denominators UNAVAILABLE.

Native TEST performance requires a TestEvaluation seal for the exact fold/sample set and evaluation cutoff. AFRE-21 fused TEST outputs also retain the frozen fusion choice. TEST thresholds must be predeclared. AFRE-19 trial and TEST reuse context stays attached and does not automatically change health severity. Monitoring never tunes the threshold or model from TEST.

AFRE-18 gross/cost/net/turnover/break-even diagnostics retain native hypothetical research identities, cutoffs and quality. Cost drift is not portfolio construction, risk optimization or execution. Native stability metrics may supply explicit incremental-value context where their metric semantics are declared. No predictive or cost metric proves trading profitability.
