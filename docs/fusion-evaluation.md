# Fusion evaluation, trial accounting and selection boundary

FusionComparison evaluates a single frozen artifact on VALIDATION or sealed TEST. It requires an explicit FusionTrialPool from AFRE-19. Every inspected declared rule is a native phase-21 trial opportunity; failed attempts require explicit native protocol forecast anchors and remain represented. The engine does not infer unregistered experiments. Native AFRE-19 completion/reuse controls remain authoritative.

Fused and every component metric use the same exact sample/truth intersection. Incomplete component grids and unavailable truth are recorded exclusions. MSE, MAE, RMSE, mean error, directional accuracy, R-squared and descriptive correlations reuse native conventions. Deltas are fused-minus-component; negative error deltas are better, while positive R-squared deltas are better. No significance or profitability claim is inferred from these deltas. Exact supported laws can receive CRPS/NLL; no empirical density is invented. Per-origin IC and rank-IC preserve insufficient/constant states.

AFRE-20 owns selection among fusion candidates. No fusion candidate adapter, source-subset optimizer or second selection framework is implemented. Upstream SelectionResult can be explicitly attached only when it names an actual contributor; it does not select fusion weights and must be available before the fusion declaration. Comparing multiple rules does not grant authority to choose a TEST winner. FrozenFusionTestChoice supports only one externally predeclared final artifact, available and chosen by the TRAIN cutoff, before TEST origins; native TestEvaluation records truth access. VALIDATION and TEST cannot learn weights or transforms.

AFRE-18 can evaluate target-unit fused returns under separately declared hypothetical cost/exposure assumptions. Costs do not select contributors or tune fusion. AFRE-15 uncertainty and exact AFRE-17 EnvironmentMetric context attach separately after computation without changing weights. Predictive improvement does not establish trading profitability; portfolio construction, risk optimization and execution remain downstream projects.

SQLite migration 21→22 is additive and transactional. Canonical payload hashes, exact projections/links and semantic replay reject corruption and valid-hash forgeries. Bounds cover source columns, rows, components, diagnostics, stored artifacts, comparisons, payload/snapshot/publication bytes/rows and lineage. Fit/application/evaluation pin read snapshots; concurrent source/target corrections or additional specs cannot alter old artifacts. Fresh seed/reversal and restart fixtures compare semantic bytes.

Non-target-unit scalar blends (including dimensionless standardized and ordinal rank signals) cannot enter target-error statistical trials or return-cost evaluation without an explicit unit bridge. Native target-metric adapters reject them. They remain valid frozen signal outputs; no automatic return interpretation is made.
