# Immutable health snapshots and replay

HealthMetric pins spec/request/rule, both window identities, admitted observation and used sample IDs, observed counts, reference/current values, current-minus-reference delta, safe ratio, rule score, status/reason, exclusions, quality states, exact truth IDs, reliability details, orientation, cutoff, availability and TEST seal. Observation IDs retain admission evidence even when missing truth/columns are excluded from scoring. No hidden imputation or omission is allowed.

ModelHealthSnapshot pins the exact full metric/rule set, monitor, status, cutoff and availability, with fixed action NONE_DESCRIPTIVE_ONLY. History queries append-only records by monitor identity. A later HEALTHY snapshot leaves earlier warnings/degradation intact. HealthDecayTrend orders caller-supplied distinct current starts against one exact reference/request/rule and reports ordinary least-squares slope per UTC nanosecond and nondecreasing adjacent fraction. It is a descriptive trend, not a change-point search or probability.

HealthRepository transactionally adds SQLite23 hlt_artifacts/records/links and immutable triggers. Prior DDL, metadata and rows remain unchanged. Indexes cover monitor/spec, target/horizon, metric/status, windows, cutoff/availability, TEST, cohort and lineage references. Canonical structured artifacts only; no executable predicates, pickle, shell, runtime network or dynamic executable imports.

Reads validate type/schema/hash, exact projections and lineage; completed references/observations/metrics/snapshots/trends/audits replay semantics before reuse. Configurable hard bounds cover metrics, two spec windows, samples, features, sources, cohorts, trends, payload/storage and lineage node/depth/bytes. Open repository read snapshots and exact pinned evidence isolate later source/target/rule corrections. Tests use an actual separate parallel SQLite writer. Hash seeds 0/1/42/random, reversed insertions and restart retain canonical semantic bytes.

The bounded HealthAudit traces exact requested features/forecasts, truth when used, windows, environment and research context. Unrelated sample targets are pruned from target-free evidence. Audit may verify truth-dependent source context even when the drift metric itself is target-free. Profile measurements are synthetic offline observations, not a production SLA.
