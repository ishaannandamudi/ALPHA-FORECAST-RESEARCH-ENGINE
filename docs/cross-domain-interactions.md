# Neutral cross-domain interactions

All sources use existing AFRE contracts. No AME/MCE/EIE/options implementation, private
class, database, sibling path or runtime plugin is imported. Downstream HFT integration
supplies adapters; AFRE does not copy provider algorithms.

Event surprise/materiality/novelty carries exact AFRE-10 scale/method/version and source
clocks. Surprise additionally requires both actual and expectation evidence. Security
FILTERED regime membership supplies the exact state probability; hard states produce
explicit0/1. No smoothing, future regime inference or hidden argmax is allowed.
An event attribute×state interaction uses ordinary PRODUCT, without a bespoke engine.

Microstructure×context and options×context use declared provider/version/schema/signal
name/version/semantics/units. Causal exact AFRE-12 expert or mixture point outputs can
cross a state feature with target/horizon agreement. They are ordinary predictors,
not MoE gating or portfolio weights. No in-sample native expert forecast is causal TRAIN
prediction evidence. Market/global/issuer/sector event/regime scalar projection is
currently unsupported rather than inferred from names or current membership.

Publication, upstream availability, actual receipt, ingestion, computation and final
availability remain distinct. Provider publication does not establish AFRE receipt.
Live/unqualified archive information is unusable before actual receipt/processing.
Qualified delivery reconstruction needs exact source/entity evidence and model-approved
attestors and retains the actual later physical clocks. It never pretends AFRE literally
ingested at the historical instant. New derived computation still uses its actual time.

Same origin/security/horizon and exact sources define prediction identity. Separate
actual1h/1d AFRE-8 architectures may reuse neutral evidence but retain independent
models, fits and forecasts. No sequence or cross-horizon pooling is implemented.
