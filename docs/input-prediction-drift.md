# Input and prediction drift

Inputs come from exact native point-in-time join and ResearchSample identities. Feature-definition fingerprints identify numeric columns. Boolean/categorical values have no automatic numeric encoding; their native values remain in the pinned upstream join and their scalar health column is absent. Numeric missingness therefore measures absence of a usable numeric value, with native quality retained. The adapter retains missing values, native quality states, source availability and later construction time. It never fills an absent feature with zero. INPUT_MEAN, INPUT_STD, INPUT_QUANTILE, INPUT_KS and STANDARDIZED_MEAN require input-grid evidence.

Population standard deviation, Type-7 quantiles, empirical KS and pooled population-standard-deviation standardized mean change are descriptive. A zero standardized denominator is UNAVAILABLE. Missingness measures absent-column fraction over admitted rows, retaining its denominator. Quality fractions count an explicitly requested quality label. Missing/unknown/excluded/late/incomparable sources remain separate in observation quality and metric exclusions.

Prediction mean/std/quantiles, strictly-positive fraction, KS and absolute mean shift use exact native point values from the frozen producer. A changed producer is INCOMPARABLE for ordinary prediction/error monitoring; fitted-parameter comparisons may explicitly pin compatible alternatives. Gaussian, empirical and compatible native mixtures support exact mean/variance/probability queries. Full mixture quantile inversion and unsupported quantile-only mixture distances are deferred. Exact calibrated intervals use their own native levels.

Input and prediction evaluation guards TargetVintage before native/health cache access. AFRE-19/20 research context is loaded as hash/schema/index-checked metadata; truth-dependent context replay belongs to audit. Input values cannot be scored as target-unit forecasts. Input drift has no causal implication for error degradation.
