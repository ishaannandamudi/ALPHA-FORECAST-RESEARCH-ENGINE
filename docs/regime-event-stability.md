# Regime and event stability

Hard filtered AFRE-11 membership uses an exact declared taxonomy/provider/state and PIT subject evidence. Soft membership uses the native ordered probabilities. Weighted MAE/MSE/RMSE/R²/sign accuracy, per-observation proper scores and reliability use explicit weights and Kish effective count. Minimum N applies to both included count and effective support. Weighted Pearson/Spearman and weighted IC are unavailable rather than silently interpreted through argmax or invented weighted ranks.

AFRE-10 events retain exact classes, subjects, availability and native pre/post/at-event windows. Optional materiality, novelty and surprise ranges pin the full unit/method/provider semantic key. Both actual and expected surprise evidence must be known by the origin. Security/issuer/sector/market/macro scope uses existing causal matching; custom executable mappings are absent. Missing, incompatible or late attributes cannot satisfy a cohort.

Supplied revisions and mapping IDs are bounded and immutable. Sector mappings cannot be replaced with a later classification. Soft-regime distribution distances are explicitly incomparable because this phase does not implement weighted empirical CDF/quantile semantics.

Event×regime and sector×regime are the only compound kinds. Each is individually declared; no grid is discovered from validation or TEST outcomes. Every comparison is descriptive and makes no event causal-effect, regime causal-invariance or significance claim.
